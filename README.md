# JC Trading Terminal

Trading terminal project.

## JC Trading Terminal 3.0 — test branch

- Development branch: `jc-terminal-3.0-dev`
- Preview purpose: isolated testing; do not merge into `main` until validated.
- Entry point: `index.html`
- Hosting: Vercel Git integration, using the repository root (`./`) and the `Other` preset.
- This branch contains the Liquidity Depth panel and the informational Quantum Risk Monitor.

The market-data panels still require functional validation in a browser, including mobile Safari. Displayed market values must be checked against the live data provider before relying on them.
